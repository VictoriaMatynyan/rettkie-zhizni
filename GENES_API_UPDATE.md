# Обновление статистики по генам

## Внесенные изменения

### 1. Добавлен новый API метод

В файле `src/services/api.js` добавлен метод:

```javascript
getQuestionnaireStatsByGene: () =>
  httpClient
    .get('/accounts/questionnaires/stats/by-gene/')
    .then(r => r.data),
```

### 2. Обновлен компонент PersonalStats.vue

#### Изменения в методе `fetchMutationsDictAndStats()`:

- Заменен вызов старого API на новый `api.accounts.getQuestionnaireStatsByGene()`
- Упрощена логика обработки данных
- Добавлена обработка ошибок с fallback на моки

#### Упрощена структура таблицы:

- Убраны колонки: "Краткое наименование", "Прочие названия", "Тип мутации", "Ссылка"
- Оставлены только: "Ген", "Количество анкет", "% от общего"

#### Обновлены тексты интерфейса:

- "Статистика по мутациям" → "Статистика по генам"
- "Количество отображаемых мутаций" → "Количество отображаемых генов"
- "При выбранных мутациях" → "При выбранных генах"

### 3. Формат данных API

#### Запрос:

```
GET /accounts/questionnaires/stats/by-gene/
Authorization: Bearer <access_token>
```

#### Ответ:

```json
{
  "ok": true,
  "items": [
    {
      "id": 1,
      "name": "MECP2",
      "count": 15
    },
    {
      "id": 2,
      "name": "CDKL5",
      "count": 8
    },
    {
      "id": null,
      "name": "Не указан",
      "count": 3
    }
  ]
}
```

### 4. Обработка ошибок

Компонент обрабатывает следующие ошибки:

- **401 Unauthorized** - отсутствие или неверный токен
- **401 Invalid Token** - неверный токен
- **401 Wrong Token Type** - нужен access токен
- **Сетевые ошибки** - fallback на моки

### 5. Совместимость

- Сохранена обратная совместимость с моками
- При ошибке API автоматически переключается на демонстрационные данные
- Все существующие функции (диаграмма, фильтры, выделение) работают с новым форматом

## Тестирование

Для тестирования создан файл `test-genes-api.js` который можно запустить в консоли браузера на странице приложения.

## Требования

- Обязательная аутентификация через Bearer токен
- Только access токен (не refresh)
- Статистика учитывает только одобренные анкеты
- Гены отсортированы по алфавиту
